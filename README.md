# CO2 Emissions Canada Analysis

#This project helps identify emission patterns, environmental trends, and insights that can support sustainability and climate-related decision-making.

#Features
- CO2 Emission Data Analysis
- Data Cleaning & Processing
- Interactive Data Visualization
- Trend Analysis
- Environmental Insights
- Report Generation

#Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI
- Jupyter Notebook

#Dataset Information
Dataset File:

CO2-Emissions_Canada.csv

The dataset contains information related to:
- Vehicle Models
- Fuel Consumption
- CO2 Emissions
- Engine Size
- Fuel Type
- Vehicle Class

#How to Run the Project

1. Clone the repository

git clone https://github.com/yourusername/CO2-Emissions-Canada.git

2. Navigate to the project folder

cd CO2-Emissions-Canada


3. Install dependencies

pip install -r requirements.txt

4. Run the analysis

python app.py

OR open:

analysis.ipynb


using Jupyter Notebook.
